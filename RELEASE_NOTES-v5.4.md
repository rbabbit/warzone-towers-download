# Warzone Towers v5.4 — Lab Sidebar (Android preview)

**Android APK — experimental/pre-release build**

## Changes

- The right-hand Research sidebar follows the currently selected laboratory.
- It shows the active topic and an ordered waiting list, with estimated research progress/time.
- Browsing catalogue entries no longer replaces the current research details of another lab.

## Download

When a release is published, download the `.apk` under **Assets**. **The public repository does not yet contain an APK release.**

## Known limits

This release was described as emulator-tested for the research UI. Some emulator terrain, physical-device support, HQ visuals, audio and general save/load behaviours were not certified. Treat it as an experimental build.
